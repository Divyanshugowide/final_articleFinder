## 🚀 Run Your Project (3 Simple Steps)

### Step 1: Start Backend
```bash
cd backend
python run.py
```
**OR use the batch file:**
```bash
START.bat
```

Wait for: `[OK] System ready`

### Step 2: Start Frontend (New Terminal)
```bash
cd frontend
python -m http.server 3000
```

### Step 3: Open Browser
Go to: **http://localhost:3000**
